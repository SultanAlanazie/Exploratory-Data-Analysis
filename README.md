# 📊 Exploratory Data Analysis Portfolio

This repository contains a collection of **Exploratory Data Analysis (EDA)** projects on various datasets.  
Each project uses **Python** with **Pandas**, **NumPy**, and visualization libraries like **Matplotlib** and **Seaborn** to explore, clean, and analyze data.

These projects were originally developed as part of the **Udacity Data Analyst Nanodegree** (“Investigate a Dataset” project) and continue to serve as a growing portfolio of data analysis work.

---

## 📁 Repository Structure
data/ # Contains all datasets
<project>.ipynb # Jupyter Notebook for each dataset analysis
<project>.html # Exported HTML report for each analysis
README.md

**Notes:**

- Each dataset is stored in the `data/` folder.  
- Each investigation has its own Jupyter Notebook and an optional HTML report for easy sharing.  
- New datasets and analysis projects can be added following the same structure.

---

## 🔍 What Each Project Includes

- Data exploration and inspection  
- Data cleaning and wrangling  
- Visualization of patterns, trends, and relationships  
- Insights and summary of findings  

> The focus is on understanding the dataset and communicating meaningful insights, rather than on predictive modeling or advanced statistics.

---

## 🧰 Tools & Technologies

- Python  
- Jupyter Notebook  
- Pandas & NumPy  
- Matplotlib & Seaborn  

> Optional: additional Python libraries may be used depending on the dataset and analysis needs.
